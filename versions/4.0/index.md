# Introduction

:::warning SKlauncher 4.0 is in open beta
You can try it today at [next.skmedix.pl](https://next.skmedix.pl). Some features are still missing and updates come out often. The stable release is still **3.2**, covered by the [3.2 documentation](/).
:::

SKlauncher 4.0 is a new major version of the game launcher for **Minecraft: Java Edition**. It was rebuilt from scratch and is built around managing **instances**, **mods**, and **modpacks**, while keeping the simple design SKlauncher is known for.

Read the [4.0 announcement post](https://next.skmedix.pl/blog/update-4-0) for the full story.

## Features

- 💄 &nbsp;Light and Dark modes, color themes, and Modern or Classic layouts
- 📦 &nbsp;One-click installs of mods, modpacks, shaders and more from Modrinth and CurseForge
- 🔄 &nbsp;Updating modpacks
- 🗂️ &nbsp;Instances for Vanilla, Forge, Fabric, Quilt, and NeoForge
- ☕ &nbsp;Automatic Java setup per instance
- 🧥 &nbsp;Changing skins, for Microsoft accounts
- 📥 &nbsp;Importing instances from many other launchers
- 📁 &nbsp;Built-in file explorer for instance files
- 🖼️ &nbsp;Screenshot gallery for each instance
- 🌐 &nbsp;Server browser provided by [Xyrios](https://xyrios.com/minecraft)
- 🤝 &nbsp;Friends list for Microsoft accounts
- 🛡️ &nbsp;Built-in malware scanner and privacy controls
- 🚀 &nbsp;Faster startup, parallel downloads, and GPU acceleration
- 🕹️ &nbsp;Every Minecraft version, from *Classic* to the latest snapshot
- 💻 &nbsp;Runs on Windows, macOS, and Linux, no Java needed

## Beta status

4.0 is not finished yet. The current focus is fixing bugs, adding the remaining features, and reading feedback. Check the [changelog](https://next.skmedix.pl/changelog) and [roadmap](https://next.skmedix.pl/roadmap) to see what is done and what is next, and report bugs on [Discord](https://next.skmedix.pl/discord).

## The team

Since its inception, SKlauncher has been developed solely by **SKmedix**, who has served as the *primary developer*. In early 2023, **Foxer** joined the team as a *Front-End developer*.

Although the team is small, **the community** plays an invaluable role: users contribute by *translating the launcher*, *testing* and reporting bugs, *moderating* the Discord server, and providing *support* to fellow users.
